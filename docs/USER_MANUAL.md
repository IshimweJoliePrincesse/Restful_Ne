# User Manual

## Register And Verify

1. Open the frontend.
2. Register with first name, last name, email, and strong password.
3. Enter the OTP sent by email.
4. Login after verification.

Inspectors register normally as `USER`. An admin upgrades their role to `INSPECTOR` from the Users page.

## Admin

- Manage users and upgrade inspectors.
- Add, edit, delete, search, sort, and filter fire extinguishers.
- Schedule inspections and assign inspectors.
- Generate reports and export CSV/PDF.
- Trigger notification checks.

## Inspector

- View assigned inspections.
- Complete inspections.
- Create maintenance logs.
- Review maintenance history.

## User

- View extinguisher status.
- Schedule/view inspection history where permitted.
- View notifications and compliance alerts.
- Update profile and change password.
